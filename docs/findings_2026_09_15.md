## 1. What changed in the story

| claim | before | after |
|---|---|---|
| the tree hierarchy contributes coverage | untested | **no**: flat ties merge_v2, benefit ≤ +0.01 |
| the geometry cannot rank real disagreement | suspected | **false**: within-axis rho = +0.755 |
| a router could recover the per-question gap | open | **closed**: nothing beats always-inject |
| merge_v2 transfers to a second graph | gate only | **yes, where it resolves**: +0.048 on ISSP |
| the judge's validation ceiling | unmeasured | human reliability 0.574, judge ceiling ~0.76 |

The structural apparatus is a good *instrument* and not the source of the
coverage gain. What survives is: retrieve relevant survey viewpoints, generate
several drafts, merge them losslessly.

## 2. ISSP transfer (second graph, one module)

`overton_responses_issp.jsonl`, 72B-AWQ, 3 rollouts, all participants judged.

| subset | n | delta | 95% CI | p |
|---|---|---|---|---|
| all questions | 60 | +0.024 | [-0.006, +0.053] | 0.11 |
| **resolved** | 34 | **+0.048** | [+0.005, +0.094] | 0.031 |
| unresolved | 26 | -0.008 | [-0.043, +0.020] | 0.65 |

The pooled null is **dilution**, not failure: 26 questions the ISSP graph cannot
reach run merge_v2 without forks, so it is baseline under another name. Expected
pooled effect (34/60) x 0.048 = +0.027 against +0.024 observed. The unresolved
subset is the control and it behaves: no forks, no difference.

Caveats: one module (Role of Government); n=34; the CI's lower bound is +0.005;
absolute scores are **not** comparable to the ATP runs, which judged 20
participants per question rather than all (`MAXU=20` re-judge queued, job
3074495).

## 3. Hierarchy ablation: flat retrieval ties

`overton_responses_flat.jsonl`, 3 rollouts, 60 questions.

| condition | OvertonScore | coverage@3 |
|---|---|---|
| baseline | 0.5026 | 0.5756 |
| merge_v2 | 0.5401 | 0.6280 |
| merge_v2_flat | 0.5504 | 0.6451 |

`merge_v2_flat` - `merge_v2` = **+0.0103, CI [-0.0113, +0.0311], p=0.34**. The
manipulation check passes: both arms retrieved on every row, volume matched (5.00
vs 4.85 forks), and flat's forks are less divergent (mean W 11.89 vs 13.74) and
slightly more relevant (0.517 vs 0.502).

Reading: removing the anchor, the descent and the child subtrees costs nothing
measurable, and the CI caps any hierarchy benefit at about +0.01. One confound
left: flat renders more subgroup lines per fork, so part of its edge may be extra
prompt content rather than the absence of hierarchy.

## 4. Where coverage is lost (cluster overlap)

| | ATP (flat run) | ISSP |
|---|---|---|
| clusters no arm covers | 98/330 (29.7%) | 211/465 (45.4%) |
| their mean relative size | 0.445 | 0.278 |
| baseline misses recovered by merge_v2 | 23.3% | 13.2% |
| size of uniquely recovered vs typical miss | 0.525 vs 0.451 | 0.459 vs 0.302 |

Two things follow. The arms recover **larger-than-typical** clusters, so neither
is reaching minority viewpoints -- the mechanism OvertonBench exists to reward.
And merge_v2 vs flat overlap at Jaccard 0.585 in what they add to baseline, which
is why the three-way union (0.6976) exceeds any pair; a same-arm rollout-to-rollout
comparison is still needed before calling that "different viewpoints" rather than
sampling variance.

## 5. The geometry ranks real disagreement (and the disagreement is small)

`validate_divergence.py --dataset opinionqa --embeddings embeddings_opinionqa_c0p5.pt`,
20,000 same-axis subgroup pairs over 2,386 axes. Ground truth is the
Jensen-Shannon divergence between the two subgroups' survey answer distributions,
which never touches the encoder.

| measure | within-axis | pooled |
|---|---|---|
| learned geodesic vs JS | **+0.755** (2027 axes) | +0.529 (null -0.000) |
| input features vs JS | +0.074 | +0.078 |

So the encoder **recovers** an ordering its own input features barely carry --
plausibly because the sibling-separation term must spread siblings along the only
axis that distinguishes them. Max-divergence selection is therefore not arbitrary,
and retraining the encoder for disagreement is **not** justified.

The magnitude is the real limit: **mean JS = 0.0154 bits** (max 0.662). Subgroups
answering the same ATP question mostly answer alike, so even perfect selection
chooses among pairs that differ very little. Read the input number as a floor: it
is cosine over distribution-weighted option text, where the shared question stem
dominates.

Not yet run: the same check on the Euclidean embedding (`--curvature 0`), which
would say whether curvature affects the ranking as well as coverage.

## 6. The judge's ceiling, measured

`judge_overtonbench.py --human_reliability` (no judge calls, free):

- split-half agreement on the 8-model ranking: mean rho **+0.402**, 95% range
  [-0.167, +0.833]
- Spearman-Brown full-sample reliability: **0.574**
- ceiling on any judge's correlation with human scores: sqrt(0.574) ~ **0.76**

Our judge's aggregate rho = 0.167 sits below that, but with only 8 models the
sampling error is enormous (see the split-half range), so **this level cannot
validate or invalidate a judge**. The informative check is judge-vs-itself within
question, which the group-reward gate computes by re-judging at a second seed.

The script previously printed "a judge cannot exceed 0.574", which is too strict;
it now prints the square-root ceiling.

## 7. Router: closed

`delta_regressor.py` on the flat run (60 questions, 120 labels). Self-test
recovers +0.924 of a planted signal and +0.000 from length alone, so the
machinery works.

| strategy | oracle gap recovered |
|---|---|
| always baseline | 0.000 |
| **always inject** | **+0.525** |
| length only | +0.118 |
| graph features | -0.040 |
| causal / all | -0.178 |

Every fitted router is below trivial always-inject, and the strongest sets are
negative. Per-feature correlations with the delta are all within +/-0.06. The
script's own stop rule fired: the result is about answer length, not routing.

Trace features were skipped as constant, because multi-pass arms stored only the
**merge** call's `<think>`, which contains no plan. That gap is now fixed in
capture (section 9) but needs a fresh run to test. Until then the router is closed
provisionally rather than on evidence.

## 8. VITAL reaches the task under its own prompt

Gate job 2706825, VITAL's shipped instruction rather than ours:

| set | resolved | median top-fork relevance |
|---|---|---|
| OvertonBench (reference) | 60/60 (100%) | 0.490 |
| VITAL | 1631/1648 (99.0%) | 0.402 |

An earlier gate under our template gave 489/500 at 0.400, so the template was not
inflating relevance. Anchors are weaker than on OvertonBench (about half the
situations sit below 0.40), so expect smaller effects and treat relevance as a
covariate. `anchor_coverage.py` now prints a distinct WEAKER ANCHORS verdict for
this case instead of the unresolved-question message.

## 9. Infrastructure and bugs fixed

- **bf16 72B does not fit 4x40GB.** `job_overton_eval.sh` defaulted to the
  full-precision model; vLLM started with 0.02 GiB of KV cache and refused to
  serve. Default is now `Qwen2.5-72B-Instruct-AWQ`, matching every other job.
- **Graph seed mismatch.** `eval_vital.py`, `anchor_coverage.py` and
  `job_anchor_coverage.sh` defaulted to seed 0 while embeddings train at 42. Node
  ids depend on the seed, so fork selection reads the wrong rows silently. All
  now default to 42.
- **VITAL generated on the wrong string.** The driver sent the bare situation
  phrase while the gate measured VITAL's own prompt; they now use the same text.
- **Gate CSV collisions.** Two `SRC=none` runs overwrite one another; pass `OUT=`
  explicitly (this already destroyed one VITAL gate result).
- **Per-draft traces were discarded.** `_merge_answer_v2` kept only drafts 1-2 of
  three and no draft's `<think>`. It now emits `draft_traces`
  (`{label, text, think, words}`), persisted by both eval drivers. Note the field
  is NOT called `drafts`: `merge_drafts` already returns `info["drafts"]`, and the
  first attempt was silently overwritten.

## 12. What can be claimed today

**Supported.** Retrieving question-relevant survey viewpoints, drafting several
answers and merging them losslessly improves Overton coverage (+0.038 to +0.050,
replicated; +0.048 on a second, independently built survey graph where it
resolves). The retrieval instrument is validated: the hyperbolic embedding ranks
measured subgroup disagreement at rho = 0.76 within axes, recovering structure its
input features do not expose.

**Ruled out as drivers.** Curvature (ΔΔ +0.005, p=0.88) and hierarchy (+0.010,
p=0.34).

**Not established.** That divergence *selection* matters (divrand, jsdiv pending);
that fork *content* matters (rand control still invalid); that the gain is not
length (no length-matched baseline); and any per-question routing policy.

**Instrument caveat on everything above.** All coverage numbers come from a judge
whose agreement with humans is 0.167 against a ceiling of about 0.76, on a
benchmark whose own human ranking reliability is 0.574.
